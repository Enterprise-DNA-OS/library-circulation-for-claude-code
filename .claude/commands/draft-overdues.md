# Write a private overdue review draft without sending

Run from the repository root:

```text
npm run library -- draft-overdues
```

Read /overdues first. Report the local draft path and the loan count. Check each due date before a human uses the text. Never send it.

Use --json when comparing records programmatically. Read docs/cli.md for dates, quoting and operating limits.
