# A staffed lending desk without a front end

Staff ask their coding agent to read records, lend a copy, register a return or prepare a branch review. The database enforces the lending constraints and the agent uses one CLI. Three read-only HTML dashboards show circulation, collection use and privacy review. They have no write buttons.

A screen gives a busy counter fast scanning, a public catalogue, self-service, mobile use and direct interaction with equipment. This base does not provide those experiences, offline circulation, RFID communication or live links to ebook providers. It is suitable for a staffed records workflow and for testing a library's own circulation rules. It is not a claim that a council's full library service can be removed in a day.

Keep the services the library needs until the connections in its custom version are tested. Enterprise DNA can build a web front end or use another stack. The value is owning the records and the rules, with the reading and writing tools chosen for the actual desk.
